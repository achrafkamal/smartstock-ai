# SmartStock AI

SmartStock AI is a stock management application with an Express/TypeScript API and an Expo mobile app.

## Project Structure

- `backend/`: API, Prisma schema and database migrations
- `mobile/`: Expo application
- `docs/`: prompts, architecture notes and API documentation

## Backend

Requires Node.js 20 or later. From `backend/`, install dependencies with `npm install`, configure the environment using `.env.example`, then run `npm run dev`. Use `npm run typecheck` to validate TypeScript and `npm run build` to compile.
